# Viyeutica

Planificación y generación inteligente de horarios escolares.

## Estado actual

Viyeutica 0.1 incluye:
- identidad visual y símbolo vectorial;
- React + TypeScript + Vite;
- Dashboard responsive;
- navegación principal;
- rutas preparadas para Centro, Curso académico, Profesorado, Grupos, Materias, Disponibilidad, Reglas, Horarios, Generación, Auditoría, Exportaciones y Configuración;
- manifest PWA;
- workflow de GitHub Pages.

## Desarrollo local

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## GitHub Pages

Vite está configurado con `base: '/viyeutica/'`.

URL prevista:

`https://aaron-casco.github.io/viyeutica/`

En GitHub: Settings → Pages → Build and deployment → Source → GitHub Actions.
